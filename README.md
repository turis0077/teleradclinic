# Telerad · demostración de sitio web (Agetel)

Sitio estático (HTML, CSS y JS): no hay que compilar nada.

## Publicar en GitHub Pages
1. Crea un repositorio y sube el contenido de esta carpeta (el `.gitignore` ya excluye el contrato Word y la carpeta `public/`).
2. En GitHub: Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
3. Abre `https://USUARIO.github.io/REPOSITORIO/`. Todas las rutas son relativas, así que funciona dentro de una subcarpeta.

Panel administrativo de demo: `admin.html` (PIN 1234).
